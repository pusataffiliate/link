Pengaturan Firebase Database & Auth

Gratis & Real-time

Petunjuk Singkat Setup Firebase & Authentication:

  1. Buka console.firebase.google.com.
  2. Buka menu Build ➔ Authentication ➔ Klik Get Started ➔ Aktifkan Email/Password provider.
  3. Buka menu Build ➔ Realtime Database ➔ Create Database ➔ Rules: test mode.
  4. Salin config keys dari Project Settings ke form di bawah ini dan klik Simpan & Sambungkan.
